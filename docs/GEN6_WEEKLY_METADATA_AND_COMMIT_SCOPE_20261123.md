# Gen6 daily/weekly coordination — 2026-11-23

## Scope / decisions
- n8n already owns the daily/weekly/intraday schedules; **no change** to n8n triggers, GitHub concurrency groups, dispatch inputs, timing or scoring.
- Preserve the existing `vnstock-main-writer` group and `cancel-in-progress: false`.
- Separate data materiality from reporting-period metadata. Limit Git staging to artifacts generated by the calling workflow.

## Change detector (Gen6)
`scripts/vnstock6_native_pipeline.py` now records per-symbol:
- `material_changed`: a financial/scoring input or a normalized statement signature changed, excluding volatile refresh/probe metadata **and `cash_flow_period`**.
- `metadata_changed`: the source-reported `latest_income_period`, `cash_flow_period` or `latest_statement_periods` changed, including backfilling previously missing periods.

Status aggregates both counters at `output/vnstock6/fundamental-status.json → counts`. 
For daily unchanged-probe results, `metadata_changed` is evaluated even when the full FHSC statement download is skipped. Failed source refreshes keep last-known-good values and do not claim either change.

`.github/workflows/vnstock6_fundamental_refresh.yml` publishes `material_changed`, `metadata_changed` and `serving_changed = material_changed OR metadata_changed` as step outputs.
Only `serving_changed=true` triggers recomputation, candidate quality gate, extended commit and Vercel revalidation. The fundamental cache/status continue to be published even when the scoring candidate is not rebuilt.

`.github/workflows/vnstock6_daily_maintenance.yml` already rebuilds and validates daily, so no change to its cadence or execution is needed.

## Acceptance / verification
1. Metadata-only period updates must produce `material_changed=0`, `metadata_changed>0`; weekly rebuilds serving if either count is nonzero.
2. No source API errors are treated as success, no synthetic BCTC period is used.
3. The existing quality gate and scoring weights remain unchanged.
4. A legacy daily/weekly Git commit must contain only the paths allowed above. Check `git show --name-only --format= <commit>` after the next scheduled run.
5. CI unit tests should PASS before merging to `main`. Changes have not altered the external n8n schedule.
